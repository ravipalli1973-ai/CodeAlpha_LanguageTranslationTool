# CodeAlpha AI Internship - Task 1: Language Translation Tool 🌐

[![CI Pipeline](https://github.com/ravipalli1973-ai/CodeAlpha_LanguageTranslationTool/actions/workflows/ci.yml/badge.svg)](https://github.com/ravipalli1973-ai/CodeAlpha_LanguageTranslationTool/actions/workflows/ci.yml)

An interactive language translation web application built with Python and Streamlit as part of the CodeAlpha Artificial Intelligence Internship.

Live Application:- https://codealpha-language-translator.streamlit.app/

## 🚀 Features
- **Multi-Language Support**: Translates text across multiple global and regional languages.
- **Accurate Translation Engine**: Integrated with translation APIs for reliable translation processing.
- **Text-to-Speech (TTS)**: Built-in audio pronunciation for translated output using `gTTS`.
- **Easy Clipboard Copy**: Dedicated one-click copy block to easily grab translated text.
- **Responsive UI**: Intuitive interface built using Streamlit.

## 🛠️ Tech Stack
- **Language**: Python 3.10+
- **Frontend / Framework**: Streamlit
- **Translation API**: `deep-translator` (MyMemory API)
- **Audio Synthesis**: `gTTS` (Google Text-to-Speech)
